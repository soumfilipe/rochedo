aviso rápido

Confirma uma ação sem tirar a pessoa do lugar. Um por vez, some sozinho (3,5 s; 6 s se tiver ação ou for erro). Para apagar, prefira aviso com “desfazer” a pedir confirmação. Erro vai com tipo: 'erro'.

import { aviso } from 'rochedo/aviso.js';
aviso('Nota apagada', { acao: { rotulo: 'desfazer', aoClicar: restaurar } });

estados: vazio, erro, carregando

Diga o que aconteceu e o que fazer a seguir. No erro, sempre ofereça “tentar de novo”. Carregando usa esqueleto no lugar do conteúdo, não um círculo girando.

nenhuma nota ainda

capture com – no início da linha ou toque em + nova nota.

não deu para carregar

sem conexão com o servidor.

ação destrutiva

Dá para desfazer? Use o aviso com “desfazer”. Não dá? Dois toques no próprio botão, sem janela de confirmação.

import { confirmar } from 'rochedo/confirmar.js';
confirmar(botao, () => apagar(id), { rotulo: 'toque de novo para apagar' });

botões

Sempre pílula, 44 px no mínimo, rótulo em mono. Uma ação principal por tela; o resto é secundário ou quieto.

<button class="ro-botao ro-botao--principal">salvar</button>

campos

Rótulo sempre visível, nunca no lugar do rótulo um placeholder. Entrada com 16 px para o iOS não dar zoom. Erro com aria-invalid e texto de apoio.

interruptor

Liga ou desliga algo que vale na hora, sem botão “salvar”. A linha toda é o alvo de toque.

<button class="ro-interruptor" role="switch" aria-checked="true"></button>

linha de lista

Item de uma lista: início (ícone ou capa), corpo com título e detalhe em mono, fim (selo ou seta). Mínimo de 56 px, separadas por filete, sem cartão.

faixa

Mensagem que fica até o problema passar: sincronização que falhou, conexão perdida. O aviso some sozinho; a faixa não. Sempre diga o que aconteceu e o que fazer.

não sincronizousem conexão com o servidor.

folha

Painel que sobe de baixo no celular (diálogo centrado em tela larga). Serve para menu de ações de um item ou para um formulário curto. ESC e toque no fundo fecham; destrutivo por último; sempre “Cancelar”.

import { abrirFolha } from 'rochedo/folha.js';
abrirFolha({ titulo: 'Livro', itens: [
  { rotulo: 'Editar', icone: 'edit', aoClicar: editar },
  { rotulo: 'Excluir', perigo: true, aoClicar: apagar } ] });

como usar

  • Sem build: copie dist/ para o projeto e ligue rochedo.css.
  • Com build: npm i github:soumfilipe/rochedo#v0.8.0 e import 'rochedo'.
  • Ícones: import { icone } from 'rochedo/icones.js'.
  • Tema: automático pela preferência do sistema, ou <html data-tema="claro|escuro">.
